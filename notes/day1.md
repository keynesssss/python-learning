# Day 1 — 小费与收入计算器

学习日期：2026-10-12

## 今天完成了什么

编写一个程序，输入工作时长和小费后，计算：
- 每小时小费
- 基本工资加小费的总收入
- 平均每小时总收入

## 学到的知识

- input() 返回字符串。
- float() 把符合数字格式的字符串转换成小数。
- 函数参数用于把数据传进函数。
- return 用于返回结果，也可以提前结束函数。
- return hours, tips 返回一个包含两个值的元组。
- hours, tips = result 把元组解包到两个变量中。
- 不带值的 return 返回 None。
- if 用于检查条件。
- try/except ValueError 用于处理数字转换失败。
- f-string 中的 :.2f 用于保留两位小数。

## 今天遇到的问题

### 无法用 calculator.hours 获取变量

hours 是函数内部的局部变量，不是函数的属性。
需要通过 return 返回，再由调用者接收。

### 解包时报 TypeError

函数返回一个整数时，不能把它拆成 hours 和 tips。
现在先把结果保存到 result，确认不是 None 后再解包。

### 为什么 abc 不能转换成数字？

字符编码和字符串表达的数值是两回事。
float('8') 得到 8.0。
float('abc') 无法解析，因此产生 ValueError。

## 测试结果

- 8小时、120小费：总收入264，每小时收入33。
- 8小时、0小费：总收入144，每小时收入18。
- 0小时：提示并结束。
- 负小费：提示并结束。
- 非数字输入：提示并结束。
